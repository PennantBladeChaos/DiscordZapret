> ### АНТИВИРУСЫ
> Антивирус может среагировать на WinDivert.  
> WinDivert перехватывает и фильтрует сетевой трафик и нужен для работы zapret.
> Этот инструмент способны использовать как безопасные, так и вредоносные программы, однако сам WinDivert вирусом не является.
>
> **Фрагмент [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) проекта [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Часть антивирусов относит файлы WinDivert к инструментам повышенного риска или хакерским средствам. В результате файл удаляется и перемещается в карантин. Название обнаружения обычно содержит `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`.
>
> Добавьте каталог zapret в исключения антивируса либо отключите обнаружение PUA (потенциально нежелательных приложений). Например, в Kaspersky есть параметр "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". При уверенной настройке исключений предпочтительно добавить исключение; если вы не полностью понимаете последствия, отключите обнаружение PUA.

## ⚙️Использование

1. Сначала включите безопасный DNS (Secure DNS).
    * В Chrome активируйте "Использовать безопасный DNS" и выберите поставщика DNS, отличный от "Поставщик по умолчанию".
    * В Firefox откройте "DNS через HTTPS", установите режим "Персональный", выберите "Выбрать провайдера/поставщика" и вручную укажите URL. Например: `https://dns.google/dns-query`, поскольку провайдер Cloudflare может быть заблокирован.
    * Windows 11 позволяет включить Secure DNS непосредственно в параметрах системы. [Инструкция](https://remontka.pro/dns-over-https-windows-11/). Для Windows 11 этот вариант рекомендуется.
    * На роутерах Keenetic включите параметр "Транзит запросов". Если его отключить, настройка и использование Secure DNS на компьютере могут работать неправильно.

2. Получите zip- или rar-архив с [последней страницы релиза](https://github.com/PennantBladeChaos/zapret-discord-youtube/releases/latest).

3. Откройте свойства загруженного архива и установите флажок "Разблокировать". Для 7-Zip и PeaZip этот пункт можно не выполнять.

4. Распакуйте архив в каталог, в пути к которому нет кириллицы и специальных символов.

5. Запустите подходящий файл:
    * Для поиска рабочей стратегии откройте **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`.
    * Чтобы включить автозапуск, выберите **`service.bat`** -> `Install Service` -> нужная стратегия.

## ℹ️Краткие описания файлов

- [**`general.bat ...`**](./general.bat) - ручной запуск стратегии.

  Отдельный запуск удобен для проверки стратегий. Результат зависит от множества условий, поэтому перебирайте варианты (**ALT**, **FAKE** и другие), пока не найдёте подходящий для себя.

- [**`service.bat`**](./service.bat) - автозапуск и дополнительные операции:
  - <ins>**`Install Service`** - добавляет выбранную стратегию в автозапуск через services.msc.</ins>
  - **`Remove Services`** - удаляет стратегию и WinDivert из служб.
  - **`Check Status`** - показывает состояние обхода и служб, включая автозапущенную стратегию и WinDivert.
  - **`Game Filter`** - меняет режим обхода для игр и других сервисов, работающих с UDP и TCP на портах выше 1023.  
  **После изменения режима стратегию необходимо перезапустить.**  
  Текущее состояние отображается в скобках: включено или выключено.
  - **`IPSet Filter`** - переключает обработку сервисов из `ipset-all.txt`.  
  Этот пункт полезен при проверке ресурса, который работает без zapret, но не работает с ним.  
  В скобках показывается состояние:
    - `none` - ни один IP не проверяется
    - `loaded` - IP сопоставляются со списком
    - `any` - под фильтр попадает любой IP
  - **`Auto-Update Check`** - включает или отключает автоматическую проверку обновлений.
  - **`Replace active fakes`** - заменяет выбранный активный fake на другой файл из каталога `bin`.
  - **`Update IPSet List`** - загружает актуальный `ipset-all.txt` из репозитория.
  - **`Update Hosts File`** - обновляет hosts <ins>**для восстановления веб-версии Telegram и подключения к голосовому чату Discord**</ins>.
  - **`Check for Updates`** - вручную проверяет наличие обновлений.
  - **`Run Diagnostics`** - ищет распространённые причины неисправности zapret.  
  В завершение можно очистить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда помогает при внезапном прекращении работы приложения.
  - **`Run Tests`** - запускает проверку стратегий:
    - `Standard tests` - тестирует сайты из `utils/targets.txt`.
    - `DPI checkers` - проверяет DPI у разных провайдеров, включая Cloudflare и Amazon.

## ☑️Распространенные вопросы и проблемы

### После запуска `general*` ничего не происходит

При запуске стратегии отдельным bat-файлом, а не через service, должен появиться процесс winws.exe. Его можно увидеть на панели задач.  
Если этого не произошло, обратитесь к [#522](https://github.com/PennantBladeChaos/zapret-discord-youtube/issues/522).

### Ни одна стратегия не подходит

- Откройте командную строку с правами администратора.
- Выполните команды по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезагрузите компьютер.

### Не работает Telegram в браузере

Откройте **`service.bat`** и выберите **`Update hosts file`**. Если текущий hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте весь текст из открытого блокнота.
  - С правами администратора откройте текстовым редактором файл `hosts` в созданной папке.
  - Добавьте скопированное содержимое в конец `hosts` или замените ранее добавленный аналогичный блок.
  - Сохраните файл и проверьте подключение. Если результата нет, убедитесь, что изменения действительно сохранились.

#### Работоспособность не гарантируется. При отсутствии результата используйте [Desktop-версию](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/PennantBladeChaos/tg-ws-proxy) или публичным прокси.

### Обход не работает или перестал работать

> [!IMPORTANT]
> **Стратегии могут со временем перестать работать.**
> Стратегия, которая работала раньше, может перестать помогать после её обнаружения.
> В проекте собраны разные варианты обхода. Если готовые стратегии не подходят, создайте новую на основе одной из них, изменив параметры.
> Описание параметров доступно [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Убедитесь, что `service.bat` -> `Run Diagnostics` не сообщает об ошибках.

- Проверьте, что нужный адрес присутствует в списках доменов или IP.

- Протестируйте другие варианты, включая **`ALT`** и **`FAKE`**.

- Выполните полную переустановку по инструкции ниже.

- Дополнительная информация есть в [#765](https://github.com/PennantBladeChaos/zapret-discord-youtube/issues/765).

### Как полностью переустановить или обновить проект?

- Сохраните добавленные вами ресурсы и данные.
- Перезапустите устройство.
- Выполните `service.bat` -> `Remove Services`.
- Запустите `service.bat` -> `Run Diagnostics`; если найдены ошибки, исправьте их и в конце выберите Y.
- Удалите старую папку zapret.
- Скачайте свежую версию [со страницы релизов](https://github.com/PennantBladeChaos/zapret-discord-youtube/releases) (`zapret-discord-youtube-...`).
- Откройте свойства архива правой кнопкой мыши. Если внизу справа есть флажок разблокировки, установите его, нажмите "Применить" и затем "ОК".
- Распакуйте архив в новую папку в корне диска, без пробелов, специальных символов и кириллицы.
- По очереди попробуйте разные скрипты `general`. Проверяйте интернет-ресурсы: если они не открываются, закройте программу через значок замка на панели задач и выберите другую стратегию.
- После нахождения рабочего варианта включите автозапуск через `service.bat` -> `Install Service` -> нужная стратегия.

### Не работает игра или приложение при включённом zapret

- В `service.bat` проверьте, что `Game Filter` имеет состояние **`disabled`**, а `IPSet Filter` - **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит реагирует на WinDivert

- Ознакомьтесь с инструкцией: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Windows 7 требует цифровую подпись драйвера WinDivert

- В каталоге [`bin`](./bin) замените `WinDivert.dll` и `WinDivert64.sys` одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7).

### После удаления через [**`service.bat`**](./service.bat) WinDivert остаётся среди служб

1. Найдите имя службы в командной строке Windows. Нажмите Win+R, введите `cmd`, затем выполните:

```cmd
driverquery | find "Divert"
```

2. Остановите и удалите найденную службу:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте, что настроен [Secure DNS](#%EF%B8%8Fиспользование).
- Отключите блокировщик рекламы: известно, что YouTube начал с ними бороться.
- Переберите остальные стратегии, особенно если раньше всё работало.
- См. также [#251](https://github.com/PennantBladeChaos/zapret-discord-youtube/discussions/251).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что включён [Secure DNS](#%EF%B8%8Fиспользование).
- Сначала определите стратегию, на которой открывается YouTube, и запустите её.
- В `service.bat` откройте `Run Diagnostics` и очистите кэш Discord.
- Проверьте приложение Discord и выясните, помогла ли очистка кэша.
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, можно пользоваться ей.
- Если Discord не открывается и в браузере, снова проверьте все стратегии. YouTube и Discord могут работать на разных вариантах.
- См. также [#252](https://github.com/PennantBladeChaos/zapret-discord-youtube/discussions/252).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Попробуйте [tg-ws-proxy](https://github.com/PennantBladeChaos/tg-ws-proxy).
- Также можно использовать бесплатные MTProto-прокси из интернета.

### Не работают игры

Игры используют разные схемы подключения, поэтому проверить и исправить каждую из них невозможно.

Попробуйте такой порядок:
- через `service.bat` обновите ipset и включите `Game Filter`;
- если это не помогло, включите также `ipset any`.

У режима `ipset any` есть побочный эффект: многие сайты могут перестать открываться. Поэтому не держите его включённым постоянно. Определите IP-адреса, используемые игрой, и внесите их в `ipset-all.txt`.

Если проблема сохраняется, создайте обсуждение в разделе [Discussions](https://github.com/PennantBladeChaos/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### Не нашли подходящего ответа

- Создайте обращение [здесь](https://github.com/PennantBladeChaos/zapret-discord-youtube/issues).

## 🗒️Добавление адресов прочих ресурсов

Дополнительные адреса для обхода указываются в следующих файлах:
- **`list-general-user.txt`** - домены; поддомены учитываются автоматически.
- **`list-exclude-user.txt`** - домены, которые нужно исключить. Например, это может быть домен из сети, чей IP уже присутствует в `ipset-all.txt`, но сам домен фильтровать не требуется.
- **`ipset-all.txt`** - IP-адреса и подсети.
- **`ipset-exclude-user.txt`** - IP-адреса и подсети, которые нужно исключить.
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`.
